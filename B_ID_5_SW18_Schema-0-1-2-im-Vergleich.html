Frau Pfister möchte im Badezimmer Licht und Ventilator separat steuern. Betätigen Sie die Schalter in den drei Schaltungen, vergleichen Sie die Schaltfolgen und bestimmen Sie die Drähte in jedem Rohr.

    Merksätze

    Schema 0 (Ausschaltung): Betriebsmittel werden von nur einer Stelle aus ein- und ausgeschaltet. Schaltfolge 0–1.

    Schema 1 (Serien- oder Stufenschaltung): Zwei Betriebsmittel werden unabhängig voneinander geschaltet. Schaltfolge 0–1–2 (1 + 2).

    Schema 2 (Gruppenschaltung oder Umschaltung): Zwei Betriebsmittel werden wechselseitig, jedoch nie gleichzeitig in Betrieb genommen. Schaltfolge 0–1–0–2.

    • Welcher Leiter kommt im Rohr zum Schalter dazu, wenn Schema 0 durch Schema 1 ersetzt wird?
